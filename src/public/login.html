Forgot your login?

There's no email reset — set a new login on the server where KanDeck runs:

Docker: docker compose exec kandeck npm run reset-password -- <username> <new-password>

Local: npm run reset-password -- <username> <new-password>

Locked out by OAuth or passkeys? Turn password sign-in back on: docker compose exec kandeck npm run auth:reset

Your boards, settings, backups and API key are kept. Full details are in the README.
