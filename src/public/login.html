Forgot your password?

There's no email reset — reset it on the server where KanDeck runs, then reload this page and set a new one:

Local: npm run reset-password

Docker: docker compose exec kandeck npm run reset-password

This clears the password so you can create a new one here. Your boards, settings, and backups are kept. Full details are in the README.
